Student Task Manager

About the Project

Student Task Manager is a simple web application designed to help students organize and manage their daily tasks.

Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Save tasks in the browser using Local Storage.
- Track remaining tasks.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Use

1. Open the application.
2. Enter a task.
3. Add the task to your list.
4. Mark tasks as completed when finished.
5. Delete tasks you no longer need.

Purpose

This project was built to practice front-end web development skills and improve my understanding of HTML, CSS, and JavaScript.
